ExplorerGO v3.1.1

A customizable Android launcher designed for simplicity, flexibility and personalization.

ExplorerGO is an Android launcher project focused on providing a clean and customizable home screen experience.

✨ Features

🏠 Customizable home screen

📱 Add applications to the home screen

🎨 Personalized launcher experience

🌍 Multi-language support

⚙️ Customization options

📦 Android APK builds through GitHub Actions

🌍 Languages

ExplorerGO includes multi-language support.

📲 Installation

Download the latest APK from the GitHub Actions Artifacts or Releases section.

Enable installation from unknown sources if required.

Install the APK.

Open ExplorerGO.

Set it as your default launcher if desired.
